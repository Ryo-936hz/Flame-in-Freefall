## Reproducción

Desde un clon de este código, `scripts/setup.ps1`, después
`node node_modules/playwright/cli.js install chromium` y `scripts/check.ps1 -E2E`.
El modo inicial es sintético y no necesita ZIP ni credenciales. Para datos reales,
seguir [DEMO](../DEMO.md): importar el paquete P2 1.1.1 en base dedicada, o definir
`FLAMELAB_P2_DEMO_BUNDLE` para el segundo E2E aislado. Nunca sustituir un corpus
existente para reproducir la prueba. [Runner y opciones](../../apps/web/tests/e2e/README.md).
