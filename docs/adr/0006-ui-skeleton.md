# ADR 0006 Interfaz técnica antes del frontend de producto

- Estado: Propuesta de diseño para implementación local; revisar contra el ZIP y el estado real del repositorio.
- Fecha: 14 de noviembre de 2026.
- Revisión: P1 y los responsables consumidores.

## Contexto

La entrega actual termina en Markdown. La siguiente fase construirá conexiones y un arnés técnico; el frontend de producto se desarrollará posteriormente.

## Decisión

Preparar cliente tipado y una interfaz técnica de integración. Documentar una dirección visual inspirada en sistemas de Anduril para Evidence Canvas y Mission Lab.

## Consecuencias

No presentar la pantalla técnica como diseño final. P5 controla componentes compartidos y P6 una frontera de Mission Lab. Los paneles generados por IA son tipos permitidos, no código libre.

## Revisión futura

Si el código o el alcance exige cambiar esta decisión, añadir un ADR que la sustituya y enlazarlo aquí. No reescribir silenciosamente su significado.
